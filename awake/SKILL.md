# Awake

先识别执行目标电脑的操作系统，再读取对应说明。使用宿主提供的操作系统信息，并在目标机器验证：macOS 用 `uname -s`（Darwin）；Windows 原生 PowerShell 用 `[System.Environment]::OSVersion.Platform`（Win32NT）。WSL、容器、SSH 远端的系统不代表用户电脑；确认命令执行目标，不在 Linux/WSL 里运行 Mac 脚本。Linux 暂不支持。

- macOS：读取 [macOS 操作说明](references/macos.md)。
- Windows：读取 [Windows 操作说明](references/windows.md)。

理解一次给出的时长，换算整数分钟（向上取整），范围 1–1440 分钟。未给时长或有歧义才询问。再次开启从当前时刻重新计时，不累加。`status` / 状态只查询；`stop` / off / 关闭直接恢复，无需先连接网络。不得把用户原话拼进 shell，只传规范化后的整数和固定动作。

首次检查控制器是否安装、权限是否具备。安装需要本机管理员授权，不能声称已安装即代表已按本次时长启动。按当前系统说明执行，然后回读状态，核对实际截止时间和恢复机制。用用户本地时区报告截止时间；不要沿用其他用户的时区。

## 网络

默认保留现有网络，不自动切换热点。如果用户要求连接手机热点，先用当前系统 Wi-Fi 界面确认目标 SSID；未提供目标且不能从上下文确定时再问。通过当前可见状态确认连接后，进行 HTTPS 联网验证；不读取或记录 Wi-Fi 密码。Windows 不能假设支持 Apple Instant Hotspot，用户可能需要在手机上开启个人热点并在系统界面首次连接。目标未连接或联网失败时不新开或延长会话，也不擅自关闭已有会话。没有可用 UI 或网络工具时明确说明缺少的验证，不声称完成。

## 交付边界

回读配置与守护任务成功，只证明软件状态；只有在该设备实际合盖并观察任务持续运行，才报告合盖实测通过。不同硬件、固件、Modern Standby、企业策略可能限制效果。到期恢复原有睡眠策略，不保证立即睡眠；不主动休眠、关机或断开网络。任务即使尚未完成，也按用户给定时长结束。保持散热，避免将仍在运行的电脑放入密闭包内。
